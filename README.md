# REDLINE // 1989

Fast top-down neon zombie action game. Godot 4.7.2 (GDScript), exported for Web, hosted on Firebase.

- Live: https://redline-1989.web.app (deploys from `main`)
- Preview: the `develop` channel, linked from each `develop` run of the GitHub Actions workflow

Clear a nightclub floor of infected with a silent pipe or loud guns, kick doors, break grabs, reach the
elevator. Plays in portrait or landscape on a phone (MOVE stick, HIT/FIRE, KICK, DASH) and with WASD + mouse.

## Working on it

`CLAUDE.md` is the source of truth for the branching rules (`feature/*` -> `develop` -> `main`), the checks
that must pass, and how the project is laid out. In short:

```sh
godot --headless --import
godot --headless --quit
godot --headless -s tests/smoke_test.gd
mkdir -p web && godot --headless --export-release "Web" web/index.html
```

## Art

Everything in `assets/sprites/` is generated by a script in `tools/` and committed. None of the tools run in
CI, and the game draws a procedural stand-in for any sprite that is missing.

| Tool | Makes | Needs |
| --- | --- | --- |
| `tools/draw_characters.py` | Player and infected animation sheet, 3/4 view | Atelier |
| `tools/draw_props.py` | Furniture, glass, neon signs and other props, 3/4 view | Atelier |
| `tools/draw_weapons.py` | Pipe, pistol and shotgun: held/HUD side views and floor pickups | Atelier |
| `tools/slice_sheets.py` | Floor textures, cut from the green-screen sheet in `assets/raw/` | Pillow |

### Atelier

[Atelier](https://github.com/marmikshah/atelier) is an offline pixel-art editor with no GUI, driven from the
command line. We use it for small, exact-size art where a generated sheet is the wrong tool: weapons, icons,
pickups, and later animation frames.

Characters and props are drawn by code (posed, lit forms with detail passes) and weapons as character grids, so
art changes show up in a diff and can be regenerated:

```sh
# install once; these options leave your shell profile and agent config alone
curl -fsSL -o /tmp/atelier-install.sh https://github.com/marmikshah/atelier/releases/latest/download/install.sh
ATELIER_NO_MODIFY_PATH=1 ATELIER_NO_CONNECT=1 sh /tmp/atelier-install.sh

python3 tools/draw_characters.py && python3 tools/draw_props.py && python3 tools/draw_weapons.py
godot --headless --import        # then commit the PNGs and their .png.import files
```

Things to know:

- Atelier is version 0.2 and its README says the code has had no line-by-line human review. It runs offline
  and only writes the files the script exports.
- It installs to `~/.local/bin`. In Claude Code cloud sessions the repo's session-start hook
  (`.claude/hooks/session-start.sh`) installs it, and Godot, automatically.

Claude Code sessions in this repo have a project skill, `.claude/skills/atelier-pixel-art/`, with the drawing
rules (scale, view, layout), the craft order, the preview loop and how to wire new art into the game. Atelier's
own three guides (`atelier-sprite`, `atelier-scene`, `atelier-review`) are vendored beside it.
